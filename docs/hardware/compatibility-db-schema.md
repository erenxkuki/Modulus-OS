# MODULUS OS — Hardware Compatibility Database Schema

Shipped with the OS as `/usr/share/modulus/hardware-db.json`. Community-contributed updates via signed patches.

## Entry schema (JSON)

```json
{
  "id": "string (vendor:model or pci-id)",
  "vendor": "string",
  "model": "string",
  "category": "gpu | cpu | storage | network | audio | bluetooth | usb | display | printer | other",
  "identifiers": {
    "pci": "vendor:device (e.g. 10de:2204)",
    "usb": "vendor:product",
    "dmi": "board/vendor/product"
  },
  "kernel_driver": "string (e.g. nvidia, amdgpu, i915)",
  "firmware": "string | null (required firmware package)",
  "compatibility": "supported | partial | unsupported | untested",
  "limitations": ["string"],
  "tested_os_versions": ["string (e.g. 0.1.0)"],
  "notes": "string",
  "contributed_by": "string",
  "verified_at": "ISO-8601 date"
}
```

## Compatibility levels

- **supported**: works out of the box, no known issues.
- **partial**: works with caveats (documented in limitations).
- **unsupported**: known not to work; do not install experimental drivers silently.
- **untested**: no data; treat as "try at your own risk" with a warning.

## Update mechanism

- DB is a signed JSON file shipped in the image.
- Updates delivered as signed delta patches via Update Manager.
- User can submit a device report (generated by Hardware Compatibility Service) to a community repo; maintainers merge after review.
- Never silently install experimental drivers based on DB entries.

## Diagnostics report (generated by Hardware Compatibility Service)

Includes: CPU, GPU, storage, network, audio, BT, USB, displays, firmware, kernel version, OS version, driver versions, and a copy of the relevant DB entry (if found). Exportable as JSON/text for support.
